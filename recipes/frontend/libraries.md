# Frontend libraries

The default libraries every frontend Stack Recipe starts from. Versions follow the version policy in `recipes/decision-guide.md` (latest stable, pinned at creation); maintenance status is confirmed when each recipe is written. The agent does not swap a default for an alternative without the user's approval.

| Category | React | Angular |
|---|---|---|
| Language | TypeScript, strict | TypeScript, strict |
| Build | Vite (SPA) | Angular CLI (standalone components, signals) |
| SSR, only when needed (ADR-0007) | React Router framework mode | `@angular/ssr` |
| Routing | React Router | built-in Router |
| Server data | TanStack Query (hooks generated by orval) | HttpClient + signals (services generated by orval) |
| Client state | Zustand, only when needed | signals; NgRx SignalStore when it gets complex |
| HTTP (`shared/http`) | axios with interceptors | HttpClient with interceptors |
| API client generation (ADR-0008) | orval | orval |
| Forms | React Hook Form | Reactive Forms |
| Validation | Zod (schemas generated by orval) | Zod |
| Styling | Tailwind (with shadcn/ui) | Tailwind (spartan/ui) or Angular Material theme |
| Design system | chosen per project; shadcn/ui recommended | chosen per project; spartan/ui or Angular Material recommended |
| Icons / toasts | lucide / sonner | lucide / the design system's default |
| Dates | date-fns, only for date inputs and pickers (display formatting comes from the backend) | date-fns, same |
| Tests | Vitest + Testing Library + MSW; Playwright optional | Vitest (or Jest) + Testing Library + MSW; Playwright optional |
| Quality | ESLint + Prettier, dependency-cruiser, Lefthook | angular-eslint + Prettier, dependency-cruiser, Lefthook |
| Package manager | pnpm | pnpm |
| i18n | none by default; added when a project needs it | none by default; added when a project needs it |
| Component catalog | none by default; Storybook added when a project has many components | none by default; Storybook added when a project has many components |
