# feat: team wall displays and pairing

Repository: ensemble-backend

## Context

The TV never signs in with GitHub: it shows a code the owner confirms, and gets a display token that only reads the wall (A3, login decisions).

## User story

As the owner, I want to put the team wall on a TV with a short code, so that the team is visible without my GitHub login on the TV.

## Acceptance criteria

- Given a TV, when `POST /v1/display-pairings` is called, then it answers `201` with `{pairingId, code, expiresAt}`, rate-limited.
- Given the owner signed in, when `POST /v1/display-pairings/confirm {code, name}` is called, then the pairing is confirmed and the TV's next `GET /v1/display-pairings/{id}` sets the `display` cookie once.
- Given a display token, when `GET /v1/wall` or `GET /v1/wall/stream` is called, then counters, roles, unread notifications and titles come back, never comment bodies.
- Given `DELETE /v1/displays/{id}`, then that TV gets `DISPLAY_TOKEN_REVOKED` at once.
- Only hashes of the codes and tokens are stored (D5).
