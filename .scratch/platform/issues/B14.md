# feat: project health

Repository: ensemble-backend

## Context

The health screen (M3) checks everything a project needs to work: the App, labels, workflows, `agents:check`, protection, scheduled tasks and their models, last wake-ups and the dispatcher.

## User story

As the owner, I want to see why a role never wakes, so that I fix the setup instead of waiting.

## Acceptance criteria

- Given a project, when `GET /v1/projects/{id}/health` is called, then each check comes with ok, warning or problem and its detail.
- Given a `run:<role>` label with no session after it, then the role's check is a problem.
- Given `POST /v1/projects/{id}/health/check`, then the checks run again now.
- The owner can mark each scheduled task as created, with its model, and issue the repository's events token (B4).
