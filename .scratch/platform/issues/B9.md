# feat: control room, ticket comments and pause all

Repository: ensemble-backend

## Context

The control room is one project's board; a comment goes to the ticket as the user (F6); "Pause all" stops new starts and lets running work finish (F4).

## User story

As the owner, I want to see a project's board and steer it, so that I can give context or stop the team.

## Acceptance criteria

- Given a project, when `GET /v1/projects/{id}/control-room` is called, then it returns the columns with their tickets, each role card with its model and the "change the scheduled task too" hint when the config and the marked task differ, and the running and queued counts.
- Given a comment, when `POST /v1/tickets/{id}/comments` is called, then it is posted on the issue as the user.
- Given `POST /v1/team/pause`, then the paused state the dispatcher reads is written and every screen gets `pause.changed`; `resume` undoes it.

## Contract changes

`GET /v1/projects/{id}/control-room`, `POST /v1/tickets/{id}/comments`, `POST /v1/team/pause|resume`.
