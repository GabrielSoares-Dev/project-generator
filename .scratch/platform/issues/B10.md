# feat: PM chat through the scheduled task API trigger

Repository: ensemble-backend

## Context

The PM chat comments on the issue as the user and starts the PM's scheduled task through its API trigger (P1a, P1b, F2). Risk R5: the `/fire` request shape must be confirmed with the owner first.

## User story

As the owner, I want to talk to the PM from Ensemble, so that ideas become tickets without opening GitHub.

## Acceptance criteria

- Before any code: the `/fire` URL, headers and body are confirmed with the owner in a comment.
- Given the PM task's URL and token, when `PUT /v1/scheduled-tasks/{id}/api-trigger` is called, then both are stored encrypted.
- Given a message for an issue, when `POST /v1/pm-chat/{projectId}/messages` is called, then it is commented as the user and the PM task is fired naming the issue; with no issue, a `needs-spec` issue is created first.
- Given no trigger stored, the answer is `ROUTINE_TRIGGER_NOT_CONFIGURED` (409); a failed `/fire` is `ROUTINE_TRIGGER_FAILED` (502) and is never retried automatically.
