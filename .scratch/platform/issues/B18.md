# feat: change a role's model through a pull request

Repository: ensemble-backend

## Context

Changing a role's model opens a pull request on the project changing `"models"` in `.agents/config.json` (models per role, spec).

## User story

As the owner, I want to switch a role's model from Ensemble, so that I do not edit the config by hand.

## Acceptance criteria

- Given `PUT /v1/projects/{id}/roles/{role}/model {model}`, then a pull request changing `"models"` is opened as the user and the control room shows the hint to change the scheduled task too until it is marked done.
- An unknown role or model is a validation problem.

## Contract changes

`PUT /v1/projects/{id}/roles/{role}/model`.
