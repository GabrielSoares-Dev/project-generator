# feat: team stand-up built from the events

Repository: ensemble-backend

## Context

The stand-up (F5) is built from the events, without AI: what each role finished, is doing and is waiting for.

## User story

As the owner, I want a short daily summary, so that I know where the team is in seconds.

## Acceptance criteria

- Given the last day's events, when `GET /v1/standup` is called, then each role has finished, doing and blocked lines, with ticket references.
- The daily digest notification (B12) uses the same text.

## Contract changes

`GET /v1/standup`.

AI summaries.
