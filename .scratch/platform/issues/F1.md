# feat: app shell, login and account menu

Repository: ensemble-frontend

## Context

The shell of every screen: side menu with the project selector (a chip on the phone), the login screen, the guard, "Session expired" keeping drafts, and the account menu (design boards 10 and the current-project rule).

## User story

As the owner, I want to sign in and always know which project I am in, so that I never act on the wrong one.

## Acceptance criteria

- Given no session, when any screen opens, then the login screen with "Entrar com GitHub" shows.
- Given `AUTH_NOT_OWNER` or a cancelled login, then the matching screen of the design shows.
- Given `SESSION_EXPIRED`, then the "Sessão expirada" screen shows and unsent drafts come back after login.
- The project selector shows the current project on project screens and "Todos os projetos" on cross-project ones; switching it switches the screen.
- Desktop has the side menu, the phone a tab bar; touch targets are at least 44px; no accessibility violation.
